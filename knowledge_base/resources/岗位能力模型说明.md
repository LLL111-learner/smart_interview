# 岗位能力模型说明

---

## 一、Java后端能力模型

### 雷达图维度定义

#### 1. Java核心基础
**定义**：对Java语言核心特性的理解和掌握程度。
**涵盖内容**：
- 面向对象设计（封装、继承、多态）
- 集合框架（HashMap、ConcurrentHashMap、ArrayList等）
- 多线程与并发（线程池、锁机制、JUC工具）
- JVM（内存模型、GC机制、类加载、调优）
- Java新特性（Stream、Lambda、Optional）

**能力等级**：
| 等级 | 描述 |
|------|------|
| L1 入门 | 了解基本语法和常用API，能编写简单程序 |
| L2 基础 | 理解集合框架和多线程基础，能使用常见设计模式 |
| L3 熟练 | 深入理解JVM和并发原理，能分析源码 |
| L4 精通 | 精通JVM调优，理解底层实现，能解决复杂并发问题 |
| L5 专家 | 对Java生态有全面深入的理解，能指导团队技术方向 |

#### 2. 框架与中间件
**定义**：对主流开发框架和中间件的掌握程度。
**涵盖内容**：
- Spring/SpringBoot/SpringCloud
- MyBatis/MyBatis-Plus
- Redis（缓存设计、分布式锁）
- 消息队列（Kafka/RabbitMQ/RocketMQ）
- 搜索引擎（Elasticsearch）

**能力等级**：
| 等级 | 描述 |
|------|------|
| L1 入门 | 能使用框架的基本功能 |
| L2 基础 | 理解框架核心原理（IOC、AOP），能进行基本配置 |
| L3 熟练 | 深入理解框架原理，能自定义扩展和调优 |
| L4 精通 | 熟悉源码实现，能设计中间件方案解决复杂业务问题 |
| L5 专家 | 能自研中间件，对框架生态有全面理解 |

#### 3. 数据库能力
**定义**：对关系型数据库和NoSQL的设计与优化能力。
**涵盖内容**：
- MySQL（索引、事务、MVCC、锁）
- SQL编写与优化
- 数据库设计（范式、反范式）
- 分库分表方案
- NoSQL选型与应用

**能力等级**：
| 等级 | 描述 |
|------|------|
| L1 入门 | 能编写基本SQL，了解表设计 |
| L2 基础 | 理解索引原理，能进行基本的SQL优化 |
| L3 熟练 | 精通事务和锁机制，能设计合理的数据库方案 |
| L4 精通 | 能设计分库分表方案，处理海量数据存储 |
| L5 专家 | 精通数据库内核原理，能进行深度调优 |

#### 4. 系统设计能力
**定义**：对分布式系统的架构设计和技术选型能力。
**涵盖内容**：
- 微服务架构设计
- 高并发系统设计（缓存、消息队列、限流）
- 高可用设计（主从、集群、熔断降级）
- 分布式一致性（分布式事务、分布式锁）
- API设计与接口规范

**能力等级**：
| 等级 | 描述 |
|------|------|
| L1 入门 | 了解基本的系统架构概念 |
| L2 基础 | 理解微服务架构，能设计简单系统 |
| L3 熟练 | 能设计高并发、高可用的系统方案 |
| L4 精通 | 有大规模系统设计经验，能做技术选型决策 |
| L5 专家 | 能设计复杂分布式系统，有架构演进经验 |

#### 5. 工程实践能力
**定义**：在实际开发中的工程化和协作能力。
**涵盖内容**：
- 代码规范与质量
- 单元测试与集成测试
- CI/CD实践
- Git协作与Code Review
- 文档编写与技术分享

**能力等级**：
| 等级 | 描述 |
|------|------|
| L1 入门 | 能完成指定的开发任务 |
| L2 基础 | 代码规范，有基本的测试意识 |
| L3 熟练 | 有完善的工程化实践，推动团队规范 |
| L4 精通 | 建立团队工程化体系，提升整体研发效率 |
| L5 专家 | 制定技术标准和最佳实践 |

#### 6. 问题排查能力
**定义**：定位和解决线上问题的能力。
**涵盖内容**：
- 日志分析和问题定位
- JVM问题排查（OOM、CPU高、死锁）
- 性能调优（接口、SQL、JVM）
- 监控告警体系
- 应急响应和复盘

**能力等级**：
| 等级 | 描述 |
|------|------|
| L1 入门 | 能通过日志定位简单问题 |
| L2 基础 | 能使用常用工具（jstack、jmap）排查问题 |
| L3 熟练 | 有系统的排查方法论，能快速定位复杂问题 |
| L4 精通 | 能建设监控体系，预防和快速响应线上问题 |
| L5 专家 | 有丰富的疑难杂症处理经验，能指导团队 |

#### 7. 计算机基础
**定义**：对计算机基础知识的掌握程度。
**涵盖内容**：
- 数据结构与算法
- 计算机网络（TCP/IP、HTTP）
- 操作系统（进程、线程、内存管理）
- 设计模式

**能力等级**：
| 等级 | 描述 |
|------|------|
| L1 入门 | 了解基本的数据结构和算法 |
| L2 基础 | 能运用常见算法解题，理解网络协议 |
| L3 熟练 | 算法能力较强，深入理解操作系统和网络原理 |
| L4 精通 | 算法和计算机基础扎实，能灵活运用 |
| L5 专家 | 在算法竞赛或系统底层有深入研究 |

## 二、Web前端能力模型

**涵盖内容**：

## 四、提升路径说明

### Java后端提升路径
```
初级(L1-L2)：Java基础 → 集合/并发 → Spring全家桶 → MySQL基础
    ↓
中级(L2-L3)：JVM深入 → 并发编程 → Redis/MQ → SQL优化 → 微服务
    ↓
高级(L3-L4)：分布式系统 → 高并发架构 → 性能调优 → 系统设计
    ↓
资深(L4-L5)：架构演进 → 技术决策 → 团队建设 → 行业影响
```

**关键里程碑**：
- L1→L2：独立完成CRUD开发，理解Spring基本原理
- L2→L3：能排查线上问题，理解分布式系统基础
- L3→L4：能设计高可用系统，有性能调优经验
- L4→L5：能主导技术架构决策，培养团队

### Web前端提升路径
```
初级(L1-L2)：HTML/CSS/JS基础 → Vue/React入门 → 组件开发
    ↓
中级(L2-L3)：框架原理 → TypeScript → 工程化 → 性能优化基础
    ↓
高级(L3-L4)：框架源码 → 前端架构 → 深度性能优化 → 跨端开发
    ↓
资深(L4-L5)：前端基建 → 微前端 → 低代码/可视化 → 技术影响力
```

**关键里程碑**：
- L1→L2：能独立开发页面，熟练使用框架
- L2→L3：理解框架原理，有工程化实践
- L3→L4：能设计组件库/前端架构，有性能优化经验
- L4→L5：能建设前端基础设施，有行业影响力

### 通用提升建议
1. **读源码**：选择一个框架/库深入阅读源码，理解设计思想
2. **写博客**：输出倒逼输入，整理和分享所学知识
3. **做项目**：通过实际项目应用所学，积累经验
4. **参与开源**：贡献开源项目，提升技术影响力
5. **跨领域学习**：适当了解相邻领域（后端了解前端，前端了解后端）
