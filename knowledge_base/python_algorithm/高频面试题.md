## 一、Python基础（5题）

### 1. Python中的GIL是什么？它如何影响多线程程序的性能？
- **难度**：中等
- **考察点**：Python运行时机制、并发编程理解
- **要点**：GIL（全局解释器锁）是CPython中的互斥锁，同一时刻只允许一个线程执行Python字节码。CPU密集型任务多线程无法利用多核，应使用多进程（multiprocessing）或C扩展。IO密集型任务受影响较小，因为线程在IO等待时会释放GIL。

### 2. Python中装饰器的原理是什么？请手写一个带参数的装饰器。
- **难度**：中等
- **考察点**：闭包、高阶函数、Python语法糖
- **要点**：装饰器本质是一个接收函数作为参数并返回新函数的高阶函数。`@decorator` 等价于 `func = decorator(func)`。带参数的装饰器需要三层嵌套：外层接收装饰器参数，中层接收被装饰函数，内层是实际包装函数。使用 `functools.wraps` 保留原函数元信息。

### 3. Python中的生成器（Generator）和迭代器（Iterator）有什么区别？
- **难度**：基础
- **考察点**：Python惰性求值、内存效率
- **要点**：迭代器是实现了 `__iter__` 和 `__next__` 方法的对象；生成器是一种特殊的迭代器，通过 `yield` 关键字或生成器表达式创建。生成器惰性求值、节省内存，适合处理大数据流。`send()`、`throw()`、`close()` 是生成器的高级方法。

### 4. Python的深拷贝和浅拷贝有什么区别？
- **难度**：基础
- **考察点**：Python对象模型、引用机制
- **要点**：浅拷贝（`copy.copy`）创建新对象，但内部元素仍引用原对象的子对象；深拷贝（`copy.deepcopy`）递归复制所有子对象。赋值操作 `=` 只是引用绑定，不产生新对象。可变对象（list/dict）与不可变对象（tuple/str/int）的行为差异。

### 5. Python中 `*args` 和 `**kwargs` 的作用是什么？请解释函数参数传递机制。
- **难度**：基础
- **考察点**：函数参数、解包机制
- **要点**：`*args` 接收任意数量位置参数为元组，`**kwargs` 接收任意数量关键字参数为字典。参数传递遵循"传对象引用"（既非传值也非传引用），可变对象在函数内修改会影响外部。参数顺序：普通参数、`*args`、keyword-only参数、`**kwargs`。

## 二、数据结构与算法（6题）

### 6. 请解释动态规划的基本思想，并举例说明。
- **难度**：中高
- **考察点**：算法思维、最优子结构、状态转移
- **要点**：将复杂问题分解为重叠子问题，通过存储子问题解避免重复计算。三要素：最优子结构、重叠子问题、状态转移方程。经典问题：背包问题、最长公共子序列、编辑距离、斐波那契数列。自顶向下（记忆化搜索）vs 自底向上（表格法）。

### 7. 哈希表的原理是什么？如何处理哈希冲突？Python的dict底层实现？
- **难度**：中等
- **考察点**：数据结构、哈希函数、冲突处理
- **要点**：哈希函数将键映射到数组索引，冲突处理方法有链地址法和开放寻址法。Python dict使用开放寻址法（二次探测），CPython 3.6+采用紧凑字典（分离索引数组和键值数组），保持插入顺序且更省内存。平均O(1)查找，最坏O(n)。

### 8. 请实现快速排序，并分析其时间复杂度和空间复杂度。
- **难度**：中等
- **考察点**：排序算法、分治法、复杂度分析
- **要点**：选取pivot，将数组分为小于和大于pivot的两部分，递归排序。平均O(nlogn)，最坏O(n²)（已排序数组+选首元素为pivot）。空间复杂度O(logn)（递归栈）。优化：三数取中选pivot、随机化、小数组切换插入排序。不稳定排序。

### 9. 二叉树的常见遍历方式有哪些？如何不使用递归实现？
- **难度**：中等
- **考察点**：树的遍历、栈的应用、递归与迭代转换
- **要点**：前序（根左右）、中序（左根右）、后序（左右根）、层序（BFS）。非递归实现：前序/中序用显式栈模拟；后序可用双栈法或标记法；层序用队列。Morris遍历可以做到O(1)空间。

### 10. 什么是图的BFS和DFS？各有什么应用场景？
- **难度**：中等
- **考察点**：图论基础、搜索策略
- **要点**：BFS用队列，逐层探索，适合最短路径（无权图）、层次遍历；DFS用栈或递归，深入探索，适合连通性检测、拓扑排序、环检测。时间复杂度均为O(V+E)。BFS空间O(V)，DFS空间O(V)最坏。

### 11. 请解释时间复杂度和空间复杂度的概念，分析常见操作的复杂度。
- **难度**：基础
- **考察点**：算法分析基础
- **要点**：大O表示法描述随输入规模增长的渐进上界。常见复杂度：O(1) < O(logn) < O(n) < O(nlogn) < O(n²) < O(2^n)。Python常见操作：list append O(1)均摊，list insert O(n)，dict查找O(1)均摊，set查找O(1)均摊。需区分最好/最坏/平均情况。

## 三、机器学习基础（5题）

### 12. 请解释偏差-方差权衡（Bias-Variance Tradeoff）。
- **难度**：中等
- **考察点**：模型泛化理论
- **要点**：偏差衡量模型预测值与真实值的偏离程度（欠拟合），方差衡量模型对数据变化的敏感程度（过拟合）。简单模型高偏差低方差，复杂模型低偏差高方差。总误差 = 偏差² + 方差 + 噪声。正则化、交叉验证、集成学习是平衡偏差方差的常用手段。

### 13. 解释L1正则化和L2正则化的区别，各有什么效果？
- **难度**：中等
- **考察点**：正则化技术、特征选择
- **要点**：L1（Lasso）添加参数绝对值之和惩罚，产生稀疏权重（特征选择效果），对应拉普拉斯先验；L2（Ridge）添加参数平方和惩罚，使权重趋近于零但不为零，对应高斯先验。L1在菱形约束边界上交坐标轴的概率大，所以能产生零权重。ElasticNet结合两者。

### 14. 随机森林和梯度提升树（GBDT）的区别是什么？
- **难度**：中高
- **考察点**：集成学习、Bagging vs Boosting
- **要点**：随机森林是Bagging方法，并行训练多棵树取平均/投票，降低方差，对过拟合鲁棒；GBDT是Boosting方法，串行训练，每棵树拟合前一轮的残差，降低偏差，容易过拟合需调参。随机森林对特征做随机采样。XGBoost/LightGBM是GBDT的高效实现，加入正则化和并行优化。

### 15. 什么是交叉验证？为什么需要它？
- **难度**：基础
- **考察点**：模型评估方法
- **要点**：将数据分为K折，每次用K-1折训练，1折验证，重复K次取平均。解决单次划分的随机性，更可靠地评估模型泛化能力。常用K=5或10。变体：分层K折（保持类别比例）、Leave-One-Out（K=N）、时间序列交叉验证（不能打乱时间顺序）。

### 16. SVM的核心思想是什么？什么是核函数？
- **难度**：中高
- **考察点**：支持向量机原理
- **要点**：SVM寻找最大间隔超平面分离数据，只依赖支持向量。软间隔允许部分误分类（参数C控制）。核函数将数据映射到高维空间使其线性可分，无需显式计算高维坐标（核技巧）。常见核：线性核、多项式核、RBF高斯核。RBF核通用性强但需调γ参数。

## 四、深度学习（4题）

### 17. Transformer的自注意力机制是如何工作的？
- **难度**：中高
- **考察点**：Transformer架构、注意力机制
- **要点**：输入通过三个线性变换得到Q（Query）、K（Key）、V（Value）矩阵。注意力权重 = softmax(QK^T / √d_k)，d_k是缩放因子防止点积过大。多头注意力将QKV投影到多个子空间并行计算注意力后拼接。自注意力捕获序列内任意位置间的依赖关系，时间复杂度O(n²d)。

### 18. 梯度消失和梯度爆炸问题是什么？如何解决？
- **难度**：中等
- **考察点**：深度网络训练问题
- **要点**：反向传播中梯度逐层相乘，激活函数导数小于1时梯度指数衰减（消失），大于1时指数增长（爆炸）。解决方案：使用ReLU/Leaky ReLU替代Sigmoid/Tanh、BatchNorm/LayerNorm、残差连接（ResNet）、合理的权重初始化（He/Xavier）、梯度裁剪（Gradient Clipping）、LSTM/GRU的门控机制。

### 19. CNN中卷积层的作用是什么？请解释卷积、池化、全连接层的功能。
- **难度**：中等
- **考察点**：CNN架构理解
- **要点**：卷积层通过滑动卷积核提取局部特征（参数共享、局部连接），浅层提取边缘/纹理，深层提取语义特征。池化层（最大池化/平均池化）下采样降低特征图尺寸，增加感受野，提供平移不变性。全连接层整合全局特征用于分类。输出特征图尺寸 = (输入-卷积核+2*padding)/stride + 1。

### 20. 什么是过拟合？在深度学习中有哪些防止过拟合的方法？
- **难度**：中等
- **考察点**：模型泛化、正则化技术
- **要点**：模型在训练集上表现好但在测试集上表现差。方法：数据增强（Data Augmentation）、Dropout（训练时随机丢弃神经元）、L1/L2正则化（Weight Decay）、早停（Early Stopping）、BatchNorm、增加训练数据、减小模型复杂度、标签平滑（Label Smoothing）、MixUp/CutMix。

## 五、数据处理（3题）

### 21. NumPy的广播机制是什么？请举例说明。
- **难度**：中等
- **考察点**：NumPy核心概念、向量化计算
- **要点**：不同shape的数组运算时，NumPy自动扩展较小数组以匹配较大数组。规则：从末尾对齐维度，每个维度要么相同、要么其中一个为1、要么其中一个不存在。例如 (3,4) + (4,) → (3,4)+(1,4) → (3,4)；(3,1) + (1,4) → (3,4)。广播避免显式循环和数据复制，大幅提高性能。

### 22. Pandas中如何高效处理大数据集？有哪些性能优化技巧？
- **难度**：中等
- **考察点**：Pandas性能优化、数据工程能力
- **要点**：使用适当数据类型（category代替object、int8代替int64）、避免循环用向量化操作、使用 `apply` 时尽量用内置向量函数替代、`read_csv` 时指定 `dtype` 和 `usecols`、分块读取（`chunksize`）、使用 `query()` 和 `eval()` 减少内存、考虑使用Polars/Dask处理超大数据。

### 23. 如何处理数据中的缺失值和异常值？
- **难度**：中等
- **考察点**：数据预处理、数据质量
- **要点**：缺失值处理：删除（样本少时不推荐）、均值/中位数/众数填充、前向/后向填充（时序数据）、模型预测填充（KNN/回归）、标记为特殊类别。异常值检测：3σ原则、IQR方法、孤立森林、LOF。处理：删除、截断（Winsorize）、变换（对数/Box-Cox）、单独建模。需根据业务理解判断异常值是否有意义。

## 六、模型部署与优化（2题）

### 24. 模型部署到生产环境有哪些常见方案？
- **难度**：中高
- **考察点**：工程化能力、MLOps
- **要点**：ONNX格式标准化导出，支持跨框架部署；TensorRT/OpenVINO硬件加速推理；Flask/FastAPI搭建REST API服务；TorchServe/TF Serving专用模型服务器；Docker容器化部署；Kubernetes弹性伸缩；边缘部署（TFLite/NCNN）；模型量化（INT8/FP16）减小体积加速推理；模型剪枝、知识蒸馏减小模型。

### 25. 如何评估和优化模型的推理性能？
- **难度**：中高
- **考察点**：性能优化、系统思维
- **要点**：指标：延迟（Latency）、吞吐量（Throughput）、内存占用。优化方法：模型量化（FP32→FP16→INT8）、算子融合、动态batching、模型剪枝、知识蒸馏、使用TensorRT/ONNX Runtime加速、异步推理、GPU多流并行。Profiling工具：PyTorch Profiler、NVIDIA Nsight。需在精度和速度间权衡。
