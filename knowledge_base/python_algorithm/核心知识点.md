## 一、Python GIL、装饰器、生成器、多线程/多进程

### 1.1 GIL（全局解释器锁）
- **本质**：CPython解释器中的互斥锁，确保同一时刻只有一个线程执行Python字节码
- **原因**：CPython的内存管理（引用计数）不是线程安全的
- **影响**：CPU密集型任务多线程无法利用多核，性能甚至不如单线程（线程切换开销）
- **规避方案**：
  - `multiprocessing` 多进程（每个进程有独立GIL）
  - C扩展释放GIL（NumPy的底层运算）
  - 使用其他解释器（PyPy、Jython无GIL）
  - `concurrent.futures.ProcessPoolExecutor`
- **IO密集型**：多线程仍有效，IO等待时释放GIL

### 1.2 装饰器
- **原理**：闭包 + 高阶函数，`@decorator` 等价于 `func = decorator(func)`
- **常见用途**：日志记录、性能计时、缓存（`@lru_cache`）、权限验证、重试机制
- **带参数装饰器**：三层嵌套函数
- **类装饰器**：实现 `__call__` 方法
- **`functools.wraps`**：保留被装饰函数的 `__name__`、`__doc__` 等元信息
- **装饰器执行顺序**：多个装饰器从下到上执行（洋葱模型）

### 1.3 生成器
- **创建方式**：`yield` 关键字函数、生成器表达式 `(x for x in range(n))`
- **惰性求值**：按需生成值，不一次性加载到内存
- **高级方法**：`send(value)` 向生成器发送值、`throw()` 抛异常、`close()` 关闭
- **`yield from`**：委托子生成器，简化嵌套生成器代码
- **应用场景**：大文件逐行读取、无限序列、数据流处理管道、协程基础

### 1.4 多线程与多进程
- **threading模块**：`Thread`、`Lock`、`RLock`、`Semaphore`、`Event`、`Condition`
- **multiprocessing模块**：`Process`、`Pool`、`Queue`、`Pipe`、`Manager`
- **concurrent.futures**：统一接口，`ThreadPoolExecutor`、`ProcessPoolExecutor`
- **asyncio**：协程异步编程，`async/await` 语法，事件循环，适合高并发IO
- **选择策略**：CPU密集用多进程，IO密集用多线程或asyncio

## 二、常见算法

### 2.1 排序算法
| 算法 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|------|---------|---------|------|--------|
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 插入排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 归并排序 | O(nlogn) | O(nlogn) | O(n) | 稳定 |
| 快速排序 | O(nlogn) | O(n²) | O(logn) | 不稳定 |
| 堆排序 | O(nlogn) | O(nlogn) | O(1) | 不稳定 |
| 计数排序 | O(n+k) | O(n+k) | O(k) | 稳定 |

- Python内置 `sorted()`/`list.sort()` 使用Timsort（归并+插入），稳定，最坏O(nlogn)

### 2.2 搜索算法
- **线性搜索**：O(n)，无序数据
- **二分搜索**：O(logn)，有序数据，注意边界条件（左闭右开/左闭右闭）
- **BFS**：广度优先，队列实现，适合最短路径
- **DFS**：深度优先，栈/递归实现，适合路径枚举

### 2.3 动态规划
- **核心思想**：最优子结构 + 重叠子问题 + 状态转移方程
- **解题步骤**：定义状态 → 推导状态转移方程 → 确定初始条件和边界 → 确定计算顺序
- **经典问题**：
  - 背包问题（0-1背包、完全背包、多重背包）
  - 最长公共子序列（LCS）
  - 最长递增子序列（LIS）
  - 编辑距离
  - 股票买卖问题
- **空间优化**：滚动数组，将二维DP优化为一维

### 2.4 贪心算法
- **核心思想**：每步选择局部最优解，期望得到全局最优解
- **适用条件**：贪心选择性质 + 最优子结构
- **经典问题**：活动选择、哈夫曼编码、Dijkstra最短路径、最小生成树（Prim/Kruskal）
- **与动态规划的区别**：贪心不回退、不考虑所有子问题

## 三、机器学习

### 3.1 线性回归
- **模型**：y = Xw + b，最小化MSE损失
- **求解**：正规方程（闭式解）或梯度下降
- **正规方程**：w = (X^T X)^(-1) X^T y，数据量大时计算代价高
- **梯度下降**：批量GD、随机SGD、小批量Mini-batch SGD
- **评估指标**：MSE、RMSE、MAE、R²
- **多项式回归**：添加特征的高次项

### 3.2 决策树
- **分裂标准**：信息增益（ID3）、信息增益比（C4.5）、基尼指数（CART）
- **剪枝**：预剪枝（限制深度/叶节点数/最小样本数）、后剪枝（代价复杂度剪枝）
- **优点**：可解释性强、无需特征缩放、处理非线性
- **缺点**：容易过拟合、不稳定、不擅长线性关系

### 3.3 SVM（支持向量机）
- **线性SVM**：寻找最大间隔超平面，max 2/||w|| s.t. y_i(w·x_i + b) >= 1
- **软间隔**：引入松弛变量ξ和惩罚参数C
- **核技巧**：通过核函数隐式映射到高维空间
- **核函数**：线性核、多项式核、RBF核、Sigmoid核
- **SMO算法**：高效求解SVM对偶问题

### 3.4 集成学习
- **Bagging**：并行训练，有放回采样，降低方差（随机森林）
- **Boosting**：串行训练，每轮关注错误样本，降低偏差（AdaBoost/GBDT/XGBoost）
- **Stacking**：多模型输出作为新特征，由元学习器整合
- **XGBoost特点**：二阶泰勒展开、正则化、列采样、处理缺失值、并行特征分裂
- **LightGBM特点**：直方图加速、GOSS梯度采样、EFB特征捆绑、leaf-wise生长

## 四、深度学习

### 4.1 CNN（卷积神经网络）
- **核心组件**：卷积层（特征提取）、池化层（下采样）、全连接层（分类）
- **关键概念**：感受野、参数共享、局部连接、特征图
- **经典网络**：LeNet → AlexNet → VGG → GoogLeNet → ResNet → EfficientNet
- **ResNet核心**：残差连接 F(x) + x，解决深层网络退化问题
- **1x1卷积**：通道变换、降维、增加非线性

### 4.2 RNN/LSTM
- **RNN问题**：长序列训练时梯度消失/爆炸，难以捕获长距离依赖
- **LSTM**：遗忘门、输入门、输出门、细胞状态，通过门控机制选择性记忆和遗忘
- **GRU**：简化版LSTM，合并遗忘门和输入门为更新门，参数更少
- **双向RNN**：同时考虑前向和后向上下文信息
- **应用**：文本分类、序列标注、机器翻译（已被Transformer替代）

### 4.3 Transformer
- **自注意力**：Attention(Q,K,V) = softmax(QK^T/√d_k)V
- **多头注意力**：多个注意力头并行计算，捕获不同子空间的关系
- **位置编码**：正弦/余弦位置编码，或可学习位置编码
- **编码器结构**：多头自注意力 + FFN + 残差连接 + LayerNorm
- **解码器结构**：掩码自注意力 + 交叉注意力 + FFN
- **优势**：并行计算、长距离依赖、可扩展性强

### 4.4 注意力机制
- **Soft Attention**：对所有位置加权求和，可微分
- **Hard Attention**：选择单个位置，不可微分，需RL训练
- **Self-Attention**：序列内部元素间的注意力
- **Cross-Attention**：不同序列间的注意力（如编码器-解码器）
- **多头注意力**：不同头关注不同类型的关系

## 五、损失函数、优化器、正则化

### 5.1 损失函数
- **回归**：MSE（均方误差）、MAE（平均绝对误差）、Huber Loss（结合两者）
- **分类**：交叉熵损失（Cross-Entropy）、Focal Loss（处理类别不平衡）
- **二分类**：Binary Cross-Entropy = -[y·log(p) + (1-y)·log(1-p)]
- **多分类**：Categorical Cross-Entropy = -Σ y_i·log(p_i)
- **对比学习**：Triplet Loss、Contrastive Loss、InfoNCE

### 5.2 优化器
- **SGD**：基本随机梯度下降，可加动量（Momentum）和Nesterov加速
- **Adam**：自适应学习率，结合动量和RMSprop，最常用
- **AdamW**：修正Adam的权重衰减实现，解耦L2正则化和自适应学习率
- **学习率调度**：StepLR、CosineAnnealingLR、OneCycleLR、Warmup

### 5.3 正则化
- **L1/L2正则化**：权重惩罚项
- **Dropout**：训练时随机丢弃神经元，测试时乘以保留概率
- **BatchNorm**：归一化层输入，加速训练，有轻微正则化效果
- **LayerNorm**：对单样本归一化，适用于NLP/Transformer
- **数据增强**：随机翻转、裁剪、颜色扰动、MixUp、CutMix
- **Early Stopping**：验证集损失不再下降时停止训练

## 六、特征工程与数据清洗

### 6.1 特征工程
- **数值特征**：标准化（Z-score）、归一化（Min-Max）、对数变换、Box-Cox变换
- **类别特征**：独热编码、标签编码、目标编码、频率编码、嵌入（Embedding）
- **时间特征**：提取年月日时、星期几、是否节假日、时间差
- **文本特征**：TF-IDF、Word2Vec、FastText、BERT嵌入
- **特征选择**：方差过滤、相关性分析、互信息、L1正则化、树模型特征重要性
- **特征交叉**：多项式特征、手动构造交互特征

### 6.2 数据清洗
- **缺失值**：删除、均值/中位数/众数填充、KNN填充、多重插补（MICE）
- **异常值**：3σ原则、IQR（四分位距）、孤立森林、Z-score
- **重复值**：`drop_duplicates()`
- **数据类型转换**：字符串转数值、日期解析
- **不一致数据**：统一格式、拼写纠正、大小写统一

## 七、模型评估指标

### 7.1 分类指标
- **准确率（Accuracy）**：正确预测数 / 总样本数，类别不平衡时不可靠
- **精确率（Precision）**：TP / (TP + FP)，预测为正中实际为正的比例
- **召回率（Recall）**：TP / (TP + FN)，实际为正中被正确预测的比例
- **F1-Score**：精确率和召回率的调和平均，2PR/(P+R)
- **AUC-ROC**：ROC曲线下面积，衡量模型区分正负样本的能力，不受阈值和类别分布影响
- **混淆矩阵**：TP、TN、FP、FN的二维表格
- **PR曲线**：类别严重不平衡时比ROC更有参考价值

### 7.2 回归指标
- **MSE**：均方误差，对大误差敏感
- **RMSE**：MSE开根号，与目标值同量纲
- **MAE**：平均绝对误差，对异常值更鲁棒
- **R²**：决定系数，表示模型解释的方差比例，1最好，0等同于预测均值
- **MAPE**：平均绝对百分比误差，适合不同量级对比

## 八、PyTorch/TensorFlow基础

### 8.1 PyTorch核心概念
- **Tensor**：多维数组，支持GPU加速和自动微分
- **autograd**：自动微分引擎，`requires_grad=True` 跟踪计算图
- **nn.Module**：模型基类，定义 `__init__` 和 `forward`
- **Dataset/DataLoader**：数据加载和批处理
- **训练循环**：forward → loss → backward → optimizer.step → optimizer.zero_grad
- **模型保存**：`torch.save(model.state_dict(), path)`

### 8.2 TensorFlow/Keras核心概念
- **tf.Tensor**：不可变张量
- **tf.Variable**：可变参数
- **Eager Execution**：即时执行模式（TF2默认）
- **Keras Sequential/Functional API**：模型构建
- **tf.data.Dataset**：高效数据管道
- **tf.function**：将Python函数编译为计算图，提高性能

### 8.3 常用技巧
- **混合精度训练**：FP16/BF16加速训练，减少显存
- **梯度累积**：模拟大batch size
- **分布式训练**：DataParallel（单机多卡）、DistributedDataParallel（多机多卡）
- **模型冻结**：迁移学习中冻结预训练层参数
- **TensorBoard**：训练可视化
